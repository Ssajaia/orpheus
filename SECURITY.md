# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Orpheus, please report it through [GitHub Private Vulnerability Reporting](https://github.com/saba-sajaia/orpheus/security/advisories/new).

Please do not disclose vulnerabilities publicly before they have been addressed.

When submitting a report, please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- Its potential impact, if known.

Reports are accepted in English and Georgian.

## Disclosure

Security vulnerabilities will be publicly disclosed after a fix is available.
